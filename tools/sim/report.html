Holy Math Simulation

A level-60 Troll priest with the model's default buffs and consumables, run through Holy Math's fight model in four kinds of fight, each at three levels of overheal. Nobody knows a player's real overheal, so the first section shows what holds up across all of them. These are mathematical results, not a guide to a kill.
